Doxter combines a focused Markdown field with a capable parser for Craft templates. Authors get a live editing experience while developers keep dependable, extensible control over how Markdown becomes HTML.

Give authors a dedicated field for GitHub-flavoured Markdown with Live Preview support. Linkable headings, fenced code blocks, reference tags, typography helpers, and emoji cover the content patterns commonly needed for long-form publishing.

## Features

- **Markdown field:** Give authors a purpose-built editor for structured plain-text content.
- **Live Preview:** Review rendered content while working in Craft.
- **Linkable headings:** Generate named anchors for sections in longer documents.
- **Table of Contents:** Generate navigation from the document's headings.
- **Fenced code blocks:** Present technical examples with language-aware block markup.
- **Shortcodes:** Introduce reusable project components without putting HTML in the field.
- **Parsing events:** Extend or adjust output through an event-driven developer API.
- **Extensible parsing:** Register shortcodes or respond to parsing events when Markdown needs to include project-specific components. Templates can render the stored source consistently without maintaining a separate parsing stack.
