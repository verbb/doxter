Doxter combines a focused Markdown field with a capable parser for Craft templates. Authors get a live editing experience while developers keep dependable, extensible control over how Markdown becomes HTML.

Give authors a dedicated field for GitHub-flavoured Markdown with Live Preview support. Linkable headings, fenced code blocks, reference tags, typography helpers, and emoji cover the content patterns commonly needed for long-form publishing.

## Features

- Give authors a purpose-built editor for structured plain-text content.
- Generate named anchors for sections in longer documents.
- Generate navigation from the document's headings.
- Present technical examples with language-aware block markup.
- Introduce reusable project components without putting HTML in the field.
- Extend or adjust output through an event-driven developer API.
